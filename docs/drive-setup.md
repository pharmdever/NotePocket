# เชื่อม Google Drive กับ NotePocket

Google Drive เป็นตัวเลือกเสริม: ไม่เชื่อมบัญชีก็ใช้โน้ตและไฟล์ในเครื่องได้ รุ่นนี้ซิงก์โน้ต โฟลเดอร์ ตาราง SOAP ไฟล์แนบ PDF รอยเขียน กล่องข้อความ บุ๊กมาร์ก หน้าที่อ่าน และฟอนต์

## ตั้งค่าครั้งแรกจากมือถือ

1. เปิด https://console.cloud.google.com/ ด้วยบัญชีเจ้าของโปรเจกต์ หากเมนูแคบ ให้เปิดเว็บไซต์สำหรับเดสก์ท็อปใน Chrome
2. สร้างโปรเจกต์ชื่อ `NotePocket` และเลือกโปรเจกต์นี้
3. APIs & Services → Library → Google Drive API → Enable
4. Google Auth Platform → Branding → Get started: ตั้งชื่อแอป `NotePocket` และอีเมลติดต่อ
5. Audience: เลือก External หากใช้บัญชี Gmail ส่วนตัว ในช่วง Testing เพิ่ม Gmail ที่ใช้ทดสอบใน Test users
6. Data Access → Add or remove scopes: เพิ่มเฉพาะ `https://www.googleapis.com/auth/drive.appdata`
7. Clients → Create client → Application type: Android
8. Name: `NotePocket Android release`
9. Package name: `com.notepocket.notes`
10. SHA-1 certificate fingerprint:

```text
DA:82:B9:3A:79:62:C4:84:75:E1:05:8B:AA:C1:E0:7C:08:01:94:5D
```

11. Create แล้วรอให้การตั้งค่าของ Google มีผล จากนั้นติดตั้ง APK release รุ่น 0.10 ขึ้นไป
12. ในแอป: ตั้งค่า → เชื่อมบัญชีและซิงก์ Drive → เชื่อมบัญชี Google → เลือก Gmail ผู้ทดลอง → อนุญาต → ตรวจชื่อบัญชีแล้วกดเชื่อมและซิงก์

ค่า SHA-1 ข้างต้นตรวจจากใบรับรองสาธารณะของ APK release ที่ลงนามด้วยกุญแจถาวรแล้ว ไม่ใช่รหัสผ่านหรือ private key ในแอปมีปุ่มคัดลอก Package/SHA-1 ของ APK ที่ติดตั้งจริงด้วย

ไม่ต้องใส่ API key, Client Secret หรือรหัสผ่าน Google ลงในแอป การระบุแอป Android ใช้ package และใบรับรองที่ลงทะเบียนกับ Google รุ่น debug ใช้ package/certificate ต่างจาก release จึงต้องลงทะเบียนแยกหากจะทดสอบ OAuth ด้วยรุ่น debug

เมื่อแจกให้คนทั่วไป ให้ตรวจ Audience/Publishing และเงื่อนไขตรวจสอบแอปของ Google อีกครั้ง บัญชี Workspace อาจมีข้อจำกัดจากผู้ดูแลระบบ ช่วง Testing อาจต้องอนุญาตใหม่ตามนโยบายของ Google

## วิธีใช้และข้อจำกัดที่ควรทราบ

- ครั้งแรกเป็นการรวมข้อมูลในเครื่องกับบัญชีที่เลือก ควรสำรอง ZIP ก่อนเริ่ม ข้อมูลหนึ่งชุดในเครื่องผูกกับบัญชีเดียว; การเลือกบัญชีอื่นจะถูกปฏิเสธ ไม่ส่งโน้ตข้ามบัญชีเงียบ ๆ
- พื้นที่ `appDataFolder` เป็นพื้นที่เฉพาะแอป ไม่ใช่โฟลเดอร์ที่เปิดดูในหน้า Drive ตามปกติ สิทธิ์ที่ขอไม่ใช้เปิดอ่านไฟล์ Drive อื่นของผู้ใช้
- ไฟล์และประวัติใช้พื้นที่ในบัญชี Drive ของผู้ใช้ ไม่ต้องมีฐานข้อมูลหรือเซิร์ฟเวอร์กลางของ NotePocket แต่พื้นที่เต็ม/โควตา API/เครือข่ายยังทำให้ซิงก์ไม่ได้
- ซิงก์ครั้งแรกดาวน์โหลดเอกสารที่จำเป็นทั้งหมดมาไว้ในเครื่อง จึงเปิดออฟไลน์ได้หลังซิงก์ครบ ต้องมีพื้นที่ในเครื่องและเวลาโอนย้ายไฟล์เพียงพอ
- ปุ่มซิงก์ใช้ได้เมื่อเชื่อมบัญชีแล้ว อัตโนมัติเป็นตัวเลือกที่ผู้ใช้เปิดเอง ตั้งค่าเฉพาะเครือข่ายไม่จำกัดข้อมูลได้ Android อาจเลื่อนงานตามแบตเตอรี่/เครือข่าย และจะรอออกจากหน้าแก้ไขโน้ตหรือ PDF
- โน้ตแก้ชนกันเก็บสำเนาแยก ไม่ตัดสินเนื้อหาโดยเทียบนาฬิกามือถือเพียงอย่างเดียว หน้าที่ PDF แก้ชนกันจะมีเอกสารสำเนาพร้อมฉากของหน้าที่ขัดแย้ง ส่วนต้นฉบับและข้อมูลอีกฉบับยังอยู่
- การลบจะซิงก์ไปด้วย หากแก้ชนกับการลบจะเก็บข้อมูลที่ยังถูกใช้อ้างอิงไว้ ประวัติรุ่นเก่ายังอยู่ในเครื่อง/Drive และกู้คืนเป็นสำเนาได้จากหน้าซิงก์ การลบถาวรในหน้าหลักไม่ใช่การล้างประวัติบน Drive
- การยกเลิกเชื่อมหยุดงานอัตโนมัติและขอเพิกถอนสิทธิ์ Google ไม่ลบโน้ตในเครื่องหรือประวัติบน Drive
- รุ่นนี้ไม่ซิงก์การตั้งค่าส่วนตัว เช่น ลำดับเครื่องมือ ธีม และฟอนต์เริ่มต้น แต่ซิงก์ไฟล์ฟอนต์และการอ้างอิงฟอนต์บน PDF
- ข้อมูลส่งด้วย HTTPS ไปยัง Google Drive การเก็บในบัญชี Google ไม่ใช่ระบบเข้ารหัสแบบ end-to-end ที่ NotePocket จัดการเอง
- ขอบเขตรุ่นแรก: ไฟล์ละ 512 MiB, ฟอนต์ละ 20 MiB/รวม 30 ฟอนต์, revision ไม่เกิน 4 MiB, 50,000 รายการปัจจุบัน และประวัติ 100,000 revision หากเกินขอบเขตจะแจ้งซิงก์ไม่สำเร็จโดยไม่ตัดเนื้อหาในเครื่อง ประวัติสะสมใช้พื้นที่เพิ่มขึ้นและยังไม่มีการยุบประวัติอัตโนมัติ
- สำรอง ZIP แบบเดิมยังใช้ได้ แต่ไม่รวม token/บัญชี/ประวัติซิงก์ การกู้ ZIP เป็นการนำเข้าเป็นสำเนาใหม่ตามเดิม

## เมื่อเชื่อมไม่ได้

- รหัส 10: ตรวจ package, SHA-1, OAuth Client แบบ Android, Drive API และ Test users ให้ตรงกับ APK release ที่ติดตั้ง
- ไม่ได้อนุญาต/ยกเลิก: กลับมากดเชื่อมใหม่ ข้อมูลในเครื่องยังใช้ได้
- บัญชีไม่ตรง: ใช้บัญชีที่ผูกข้อมูลชุดนี้ไว้ ไม่ลบแอปเพื่อแก้ปัญหาโดยไม่ได้สำรองข้อมูล
- 401: กดเชื่อมใหม่เพื่ออนุญาตอีกครั้ง
- 403: ตรวจว่าเปิด Drive API แล้ว สิทธิ์ครบ พื้นที่/โควตาไม่เต็ม และบัญชีองค์กรไม่ถูกผู้ดูแลจำกัด
- อินเทอร์เน็ตขาด: รอออนไลน์แล้วกดซิงก์อีกครั้ง การส่งซ้ำมีรหัส revision เดิมเพื่อไม่สร้างโน้ตซ้ำ
