# เลือกรูปแบบก่อนพิมพ์และพรีเซ็ต · 0.14.0

- แตะจุดที่จะพิมพ์ แล้วเลือก **สี / ขนาด / หนา / เอียง / เส้นใต้ / ขีดฆ่า / ไฮไลต์** ได้ทันที ไม่ต้องลากเลือกข้อความก่อน ตัวอักษรที่พิมพ์ต่อจะใช้รูปแบบที่เลือกจนกว่าจะเปลี่ยนหรือล้างรูปแบบ
- แถบเหนือเครื่องมือแสดงสีและขนาดที่กำลังใช้ เลื่อนแถบแนวนอนเพื่อดูเครื่องมืออื่น แตะเครื่องมือหนา/เอียง/เส้นใต้/ขีดฆ่าซ้ำเพื่อเปิด–ปิด
- กด **ล้างรูปแบบ** เมื่อไม่มีข้อความที่เลือก เพื่อกลับมาพิมพ์สีดำ ขนาด 18 ตามปกติ
- หากลากเลือกข้อความ เครื่องมือยังใช้แก้ข้อความที่เลือกได้ตามเดิม ไม่เปลี่ยนข้อความอื่น รูปและแผนภาพยังอยู่ครบ
- กดไอคอนบันทึก **เปิดพรีเซ็ตรูปแบบ** บนแถบ หรือเครื่องมือ **พรีเซ็ต** → **บันทึกรูปแบบปัจจุบันเป็นพรีเซ็ต** → ตั้งชื่อ → บันทึก
- พรีเซ็ตเก็บสี ขนาด หนา เอียง เส้นใต้ ขีดฆ่า และไฮไลต์ได้พร้อมกัน เลือกชื่อพรีเซ็ตเพื่อใช้พิมพ์ต่อ ถ้ามีข้อความที่เลือกอยู่จะปรับข้อความนั้นด้วย
- ถ้าบันทึกขณะเลือกข้อความ ใช้รูปแบบจากตัวแรกที่เลือกเป็นต้นแบบ
- ชื่อซ้ำจะขอยืนยันก่อนแทนที่ บันทึกได้ 24 แบบ ชื่อละ 40 ตัวอักษร กด **จัดการพรีเซ็ต** เพื่อใช้ เปลี่ยนชื่อ หรือลบ
- รูปแบบสำหรับพิมพ์และพรีเซ็ตเก็บไว้ในเครื่อง ใช้ได้ออฟไลน์และคงอยู่เมื่อติดตั้งอัปเดตทับ พรีเซ็ตยังไม่รวมใน ZIP สำรองหรือซิงก์ Drive แต่ข้อความที่พิมพ์และรูปแบบในโน้ตไปกับการสำรอง/ซิงก์ตามเดิม
- การเลือกสีหรือบันทึกพรีเซ็ตยังไม่แก้เนื้อหาโน้ต ถ้ายังไม่ได้พิมพ์ ไม่สร้างโน้ตว่างเพิ่ม
