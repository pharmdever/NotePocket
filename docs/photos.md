# รูปภาพในเนื้อหาโน้ต (0.13 ขึ้นไป)

แตะตำแหน่งในข้อความ → เครื่องมือไอคอน **รูปภาพ** → **เลือกรูปจากเครื่อง** รูปจะแทรกระหว่างข้อความตรงเคอร์เซอร์และจดต่อด้านล่างได้

รูปที่แนบไว้เดิมมีปุ่ม **แทรกในโน้ต** ใช้ไฟล์เดิม ไม่ทำสำเนาเพิ่ม และรูปที่อยู่ในเนื้อหาจะไม่แสดงซ้ำเป็นการ์ดไฟล์แนบด้านล่าง

- วางจากคลิปบอร์ดด้วยเมนู Paste ปกติ หรือเครื่องมือรูปภาพ → **วางรูปจากคลิปบอร์ด** เมื่อแอปต้นทางคัดลอกเป็น URI รูปภาพ ไม่ใช่ลิงก์ข้อความบนเว็บ
- รองรับคีย์บอร์ดที่ส่งรูปผ่าน Android commitContent และ receive-content รูปถูกคัดลอกเข้าแอปก่อนปล่อยสิทธิ์อ่านชั่วคราว
- แตะรูป → เปิด/ซูม, เขียนข้อความก่อน/หลังรูป, เพิ่มรูปถัดจากนี้ หรือลบออกจากโน้ต
- เปิดรูปเต็มหน้า: สองนิ้วซูม ลากเลื่อน แตะสองครั้งขยาย และส่งออกต้นฉบับได้
- การลบจากเนื้อหาไม่ลบต้นฉบับในแท็บเอกสาร Undo นำรูปกลับเข้าโน้ตได้ ส่วนการลบถาวรจากเอกสารจะนำการอ้างอิงออกจากทุกโน้ตตามคำยืนยันก่อนลบ
- รองรับ JPEG, PNG, WebP, GIF แบบภาพแรก และชนิดที่ Android ของเครื่องอ่านได้ เช่น HEIC/AVIF อ่านทิศทาง EXIF โดยไม่หมุนหรือบีบอัดทับต้นฉบับ
- รูปนำเข้าไม่เกิน 32 MiB/รูป และ 200 ล้านพิกเซล วางจากคลิปบอร์ดครั้งละไม่เกิน 10 รูป โน้ตหนึ่งแสดงรูปได้ 100 รูป ภาพที่แสดงย่อขนาดและใช้แคช bitmap รวมกับ Mermaid ไม่เกิน 12 MiB

ไฟล์ต้นฉบับอยู่ในพื้นที่ส่วนตัวแอป การอ้างอิงในเนื้อหาเป็น `![รูปภาพ](notepocket-image:รหัสไฟล์)` ซึ่งซ่อนไว้ขณะจด ไม่บรรจุข้อมูลภาพขนาดใหญ่ในข้อความ ใช้เปิดออฟไลน์ได้

สำรอง ZIP รวมต้นฉบับและเปลี่ยนรหัสอ้างอิงให้ตรงกับไฟล์ใหม่เมื่อกู้คืน โดยรักษารูปแบบข้อความรอบภาพ การซิงก์ Drive ส่งทั้งรูปและเนื้อหา เมื่อแก้ชนกับการลบจะรักษาข้อมูลที่ยังถูกอ้างอิงไว้ตามระบบซิงก์เดิม ฐานข้อมูลยัง schema 8 และรูปแบบสำรอง 6
