# ปากกาบนหน้าโน้ตและตารางในเนื้อหา · 0.15.0

## เขียนทับหน้าโน้ต

กดไอคอนปากกาที่แถบเครื่องมือ → **ปากกาเขียนทับข้อความ** แล้วใช้ปากกาสไตลัสหรือนิ้วเขียนบนกรอบเนื้อหาได้ทันที ข้อความ รูป และตารางเดิมไม่ถูกเปลี่ยนเป็นรูปภาพ

เลือกสีและขนาดปากกา ไฮไลต์ด้วยลายมือ ยางลบเส้น เพิ่มพื้นที่เขียนด้านล่าง หรือล้างเฉพาะลายมือได้ ปุ่มย้อนกลับ/ทำซ้ำใช้กับลายมือได้ด้วย ยางลบลบทั้งเส้นที่ลากผ่าน เมื่อจะพิมพ์หรือแก้ช่องตาราง เลือก **พิมพ์ / เลื่อนหน้า** ก่อน ใช้สองนิ้วเลื่อนในโหมดปากกาได้

รอยเขียนเป็นเวกเตอร์ในชั้นโปร่งใสบนเนื้อหา เลื่อนไปพร้อมโน้ต ไม่ใช้ภาพขนาดใหญ่ทั้งหน้า ยึดตำแหน่งย่อหน้าที่เริ่มเขียนและปรับสัดส่วนตามความกว้างหน้า การเพิ่มข้อความก่อนรอยเขียนเลื่อนจุดยึดตาม ข้อความที่เพิ่มด้านล่างไม่ยืดรอยเขียนเดิม เมื่อหมุนจอหรือเปลี่ยนรูปแบบจนข้อความตัดบรรทัดใหม่ รูปทรงลายมือคงอยู่แต่ตำแหน่งเทียบกับแต่ละคำอาจต่างออกไป โปรดตรวจหลังจัดหน้าใหม่

สูงสุด 400 เส้น / 20,000 จุดต่อโน้ต เพิ่มพื้นที่ว่างได้รวม 20,000 dp โหมดนี้ยังไม่แปลงลายมือเป็นข้อความหรือรับรองการแยกฝ่ามือของปากกาทุกรุ่น

## ตารางในเนื้อหาเดียวกัน

แตะจุดที่จะเพิ่มตาราง → เครื่องมือ **ตาราง** → เลือกแถว/คอลัมน์ → **แทรก** ตารางจะอยู่ระหว่างย่อหน้าในกรอบเดียวกับข้อความ แตะช่องเพื่อพิมพ์ได้จริง เลื่อนตารางแนวนอนถ้ากว้างกว่าหน้าจอ

ตัวเลือกตารางมีเพิ่ม/ลบ/แทรกแถวและคอลัมน์ ความกว้าง วางจาก Excel/Sheets คัดลอก และส่งออก CSV พร้อม **เขียนก่อนตาราง / เขียนหลังตาราง**

ตารางเก่าด้านล่างยังอยู่ครบ กดตัวเลือกตาราง → **แทรกในเนื้อหาโน้ต** เพื่อย้ายเข้าตรงเคอร์เซอร์ ตารางใหญ่แสดงครั้งละ 8 แถวและเปิดแก้ไขทีละตารางเพื่อจำกัดหน่วยความจำ ข้อมูลแถวที่ซ่อนไม่ถูกลบ สูงสุด 10 ตาราง ตารางละ 30 แถว × 8 คอลัมน์เหมือนเดิม

ลายมือ ตำแหน่งตาราง ข้อมูลช่อง และข้อความที่จัดรูปแบบบันทึกอัตโนมัติ ใช้ออฟไลน์ได้ และรวมในการสำรอง ZIP / ซิงก์ Drive เดิม อุปกรณ์ที่แก้โน้ตเหล่านี้ควรอัปเดตเป็น 0.15 ขึ้นไป รุ่นเก่ายังไม่แสดงชั้นลายมือหรือตารางในเนื้อหา การแชร์ข้อความล้วนไม่รวมลายมือ
