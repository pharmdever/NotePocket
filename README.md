# NotePocket 0.5.0

แอป Android สำหรับโน้ตและเอกสารแบบออฟไลน์ ไม่มีบัญชี ไม่มีสิทธิ์อินเทอร์เน็ต

## รุ่นนี้

- เครื่องมือหลักเป็นแถบไอคอน 5 โหมดและปุ่มเพิ่มเติม แตะใช้โดยตรง ไม่มีเมนูตาราง 15 ช่อง
- ไอคอนเลือกอยู่แสดงสีเขียว พร้อมชื่อเครื่องมือที่ใช้ กดค้างที่ไอคอนเพื่อดูชื่อ และมีคำอธิบายสำหรับ TalkBack
- ปุ่มหน้าก่อนหน้า/ถัดไปแยกสองฝั่งของเลขหน้า มีลูกศรขนาดใหญ่และชื่อใต้ไอคอน
- ย้อนกลับ/ทำซ้ำเป็นชุดปุ่มลอยแยกด้านบน มีสถานะปิดเมื่อยังใช้ไม่ได้
- ซ่อนแถบเครื่องมือได้จากเพิ่มเติม และเปิดกลับด้วยปุ่มไอคอนเล็กในโหมดอ่าน/เต็มจอ


- ตัวอ่าน PDF ใช้แถบเครื่องมือขนาดเล็ก รองรับแนวนอน เต็มจอ และเมนูเครื่องมือลอยที่เลื่อนดูได้
- ไฮไลต์แบบคูณสี: รักษาสีดำของตัวอักษร แก้สีทับข้อความในรุ่นก่อน ทั้งในตัวอ่านและสำเนาส่งออก
- เลือกข้อความ: กดค้างในโหมดอ่าน หรือเลือกเครื่องมือเลือกข้อความ แล้วลากเลือกช่วง จากนั้นกดไฮไลต์หรือคัดลอก (ต้องมี text layer; ไม่ทำ OCR)
- กล่องข้อความบน PDF: แตะเพื่อเพิ่ม/แก้สี ขนาด ฟอนต์ และความกว้าง ลากเพื่อย้าย หรือลบในกล่องแก้ไข
- นำเข้าฟอนต์ .ttf / .otf จากตัวเลือกไฟล์ของ Android ขนาดไม่เกิน 20 MiB สูงสุด 30 ฟอนต์ เลือกใช้กับกล่องข้อความและเนื้อหาโน้ตได้
- ตั้งค่า: พอดีความกว้าง/พอดีหน้า เปิดหน้าจอค้าง ความเข้มไฮไลต์ ฟอนต์เริ่มต้น จัดการฟอนต์ และคืนค่าเฉพาะการตั้งค่า


- หน้ารวมโน้ตแบบการ์ด ค้นหาชื่อ/เนื้อหา ปักหมุด โฟลเดอร์ และถังขยะที่กู้คืนได้
- เขียนโน้ต บันทึกอัตโนมัติหลังหยุดพิมพ์ 650 ms และเมื่อออกจากหน้า
- ตัวหนา ตัวเอียง และเช็กลิสต์แบบแตะสลับ ☐ / ☑ ที่บรรทัดปัจจุบัน
- นำเข้าไฟล์ หรือแนบเอกสารที่เก็บไว้แล้วกับโน้ตโดยไม่คัดลอกซ้ำ
- PDF: ปากกาและไฮไลต์หลายสี ปรับขนาดเส้น ย้อนกลับ/ทำซ้ำ บันทึกอัตโนมัติ และส่งออกสำเนา PDF พร้อมรอยเขียนโดยคงข้อความเดิม
- PDF: ซูมด้วยสองนิ้ว ลากเลื่อน เปลี่ยนหน้า/เลือกเลขหน้า จำหน้าที่อ่าน บุ๊กมาร์ก และบันทึกประกอบแต่ละหน้า
- สำรองโน้ต ไฟล์แนบ บันทึก PDF และบุ๊กมาร์กเป็น ZIP เดียว กู้คืนแบบเพิ่มสำเนา ไม่ทับข้อมูลเดิม
- ส่งออกเอกสารต้นฉบับและแชร์ข้อความโน้ต

รอยเขียนและบันทึกประกอบ PDF เก็บแยกจากต้นฉบับในแอป การส่งออกผ่านเครื่องมือ → ส่งออก PDF ที่เขียนแล้วจะสร้างสำเนาที่เพิ่มเส้นเวกเตอร์ โดยคงข้อความและโครงสร้างเอกสารเดิม ยังไม่แก้ข้อความเดิมใน PDF
เลือกโหมดอ่านเพื่อเลื่อนด้วยนิ้วเดียว เลือกปากกา/ไฮไลต์เพื่อเขียน ใช้สองนิ้วซูมได้ทุกโหมด บันทึกเมื่อยกนิ้ว
จำกัด 400 เส้นและ 20,000 จุดต่อหน้า เส้นละไม่เกิน 2,000 จุด รอยเขียนในสำเนาส่งออกเป็นเนื้อหา PDF ที่รวมแล้ว ไม่ใช่ annotation object สำหรับแก้เส้นแยกในแอปอื่น
การส่งออกต้นฉบับจากหน้าเอกสารยังได้ไฟล์ต้นฉบับที่ไม่มีรอยเขียน ส่วนข้อความจดหน้านี้ไม่ได้ถูกฝังลงสำเนาส่งออก ส่วนกล่องข้อความที่เพิ่มบนหน้าจะฝังเป็นภาพโปร่งใสเพื่อคงรูปอักษรไทยและฟอนต์ที่เลือก จึงยังค้นหา/เลือกข้อความที่เพิ่มในสำเนาส่งออกไม่ได้ แต่แก้ไขกล่องเดิมในแอปได้
เช็กลิสต์ในตัวแก้ไขเป็นสัญลักษณ์ข้อความ ใช้ปุ่มรายการสลับสถานะที่บรรทัดปัจจุบัน
ไฟล์ชนิดอื่นเก็บและส่งออกได้ แต่ตัวอ่านภายในรองรับ PDF เท่านั้น
PDF ใส่รหัสผ่านยังไม่รองรับ การซูมจำกัด 1–5 เท่าและใช้ภาพเรนเดอร์ขนาดจำกัด

## ติดตั้งและอัปเดต

แพ็กเกจรุ่นใหม่: `com.notepocket.notes` / namespace: `com.notepocket.app`
รุ่นทดสอบสำหรับ CI: `com.notepocket.notes.debug` (ชื่อ NotePocket ทดลอง)
รุ่น 0.1 เดิม: `com.notepocket.app`

**อย่าลบแอป 0.1 หากยังมีข้อมูลที่ต้องการเก็บ** รุ่นนั้นลงนามด้วย debug key ที่เครื่อง CI สร้างชั่วคราว
ไม่ได้เก็บ private key ไว้ จึงไม่สามารถรับประกันการอัปเดตทับรุ่นนั้นได้
รุ่น 0.2 ขึ้นไป ใช้ package ใหม่เพื่อให้ติดตั้งอยู่ข้างรุ่นเดิมโดยไม่แตะข้อมูลเดิม
ข้อมูลในแอปเดิมจะไม่ถูกย้ายอัตโนมัติ: ส่งออกเอกสาร/แชร์ข้อความโน้ตเดิมแล้วนำเข้ารุ่นใหม่
หลังตั้งค่ากุญแจถาวร รุ่น release ต่อไปต้องใช้กุญแจเดียวกันและเพิ่ม `versionCode`

ไม่ควรแจก debug APK เป็นรุ่นใช้งานจริง ห้ามนำ debug APK ไปติดตั้งแทน release
หาก Android แจ้งว่าลายเซ็นไม่ตรง ให้หยุดและตรวจสอบ APK ไม่ควรถอนแอปเพื่อแก้ปัญหาโดยไม่สำรองข้อมูล

## กุญแจลงนามถาวร

ดู [docs/signing.md](docs/signing.md) ใช้ GitHub Actions secret เดียว: `ANDROID_SIGNING_BUNDLE`
ไม่มี private key หรือรหัสผ่านใน repository กุญแจต้องถูกเก็บสำรองโดยเจ้าของแอป
public certificate fingerprint อยู่ที่ `docs/release-certificate-sha256.txt`
workflow จะไม่สร้าง release APK ถ้ายังไม่ได้ตั้ง secret และไม่ใช้ debug key แทนโดยอัตโนมัติ

## สร้างและตรวจสอบ

เครื่องมือ: JDK 17, Gradle 8.9, Android SDK 35 / build tools 35.0.0

```sh
gradle assembleDebug assembleDebugAndroidTest lintDebug
```

ยังไม่มี Gradle wrapper ใน repository ใช้ Gradle ที่ติดตั้งแล้วหรือ GitHub Actions
workflow จะคอมไพล์ ตรวจ Lint ทดสอบ Android emulator API 35 ถ่ายภาพหน้าจอ
และสร้าง APK ทดสอบเพิ่มเลขเวอร์ชันทดสอบ 5 → 6 ติดตั้งทับด้วย `adb install -r` แล้วตรวจว่าโน้ต ไฟล์แนบ และบันทึกประกอบยังอยู่
มีการติดตั้ง APK release 0.4 เดิม → 0.5 ด้วยกุญแจถาวรจริง และตรวจข้อมูลหลัง migration
ทดสอบเส้นที่ส่งออกบนหน้าหมุน 0/90/180/270 องศา ตำแหน่ง crop box และความครบถ้วนของข้อความต้นฉบับ
ทดสอบการย้ายฐานข้อมูล 0.1 แบบ schema เดิม การกู้คืนที่ล้มเหลว และ ZIP path traversal ด้วย

เมื่อ secret พร้อมและการตรวจทั้งหมดผ่าน จะได้ artifact `NotePocket-0.5.0-install`
ซึ่งมี `app-release.apk` ลงนามด้วยกุญแจถาวร
ผลการตรวจและภาพหน้าจออยู่ใน artifact `NotePocket-QA-reports`
การทดสอบติดตั้งทับใน CI ใช้ debug package และ key เดียวกันใน job เดียว
ไม่ใช่หลักฐานว่าอัปเดตทับ APK รุ่น 0.1 ได้

## ข้อมูลและข้อจำกัด

ใช้ SQLite schema version 4 และ migration แบบเพิ่มคอลัมน์/ตารางโดยไม่ลบข้อมูล
ถังขยะใช้กับโน้ต การลบเอกสารจากคลังเป็นการลบถาวรและลบบันทึกประกอบของเอกสารนั้น
การเอาไฟล์แนบออกจากโน้ตจะเก็บไฟล์ไว้ในคลัง

แอปไม่สำรองขึ้นคลาวด์เองและปิด Android automatic backup
การถอนแอป/ล้างข้อมูลจะลบข้อมูลในพื้นที่แอป ควรใช้เมนูตั้งค่า → สำรองข้อมูล
ไฟล์สำรอง ZIP ไม่เข้ารหัส ให้เก็บในที่ปลอดภัย
ไฟล์สำรองรุ่น 0.2 (format 2) ยังนำเข้าได้ รุ่นนี้ส่งออกเป็น format 4 ที่รวมรอยเขียน กล่องข้อความ และไฟล์ฟอนต์ และ metadata สูงสุด 32 MiB
นำเข้าเอกสารสูงสุด 512 MiB ต่อไฟล์ กู้คืน archive สูงสุด 1 GiB และ 10,000 entries
ข้อมูลจำนวนมาก/อุปกรณ์พื้นที่น้อยควรตรวจพื้นที่ว่างก่อน
ยังไม่ได้รับรองการใช้งานบนอุปกรณ์จริงทุกยี่ห้อ

รายละเอียดไลบรารีที่ใช้ส่งออก PDF: [Third-party notices](docs/THIRD_PARTY_NOTICES.md)

## การเลือกข้อความและฟอนต์

ตำแหน่งข้อความอ่านจาก PDF text layer จึงขึ้นกับข้อมูลฟอนต์และลำดับข้อความในไฟล์ต้นฉบับ
หน้าสแกนหรือ PDF ที่ไม่มีข้อมูลแปลงตัวอักษรจะยังใช้ไฮไลต์แบบลากได้
เลือกข้อความโดยแตะ/ลากช่วงในโหมดเลือกข้อความ หรือกดค้างในโหมดอ่าน
ยังไม่มี OCR, text reflow, หรือการแก้ข้อความเดิมใน PDF

โหมดเต็มจอซ่อนแถบบน/ล่างและแถบระบบ แถบไอคอนและปุ่มย้อนกลับ–ทำซ้ำยังอยู่ ซ่อนได้จากเพิ่มเติม → ซ่อนแถบเครื่องมือ กด Back ครั้งแรกเพื่อออกจากเต็มจอ
ไฟล์สำรองรุ่น 0.2/0.3 ยังนำเข้าได้ กล่องข้อความและฟอนต์รุ่นนี้เพิ่มใน format 4
ค่าการตั้งค่าส่วนบุคคลไม่ได้รวมใน backup แต่ไฟล์ฟอนต์ที่อ้างอิงในกล่องข้อความถูกรวมด้วย
ฟอนต์เป็นไฟล์ที่ผู้ใช้เลือกนำเข้าเอง แอปไม่ดาวน์โหลดจากอินเทอร์เน็ตโดยอัตโนมัติ
