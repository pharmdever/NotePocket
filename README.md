# NotePocket 0.2.0

แอป Android สำหรับโน้ตและเอกสารแบบออฟไลน์ ไม่มีบัญชี ไม่มีสิทธิ์อินเทอร์เน็ต

## รุ่นนี้

- หน้ารวมโน้ตแบบการ์ด ค้นหาชื่อ/เนื้อหา ปักหมุด โฟลเดอร์ และถังขยะที่กู้คืนได้
- เขียนโน้ต บันทึกอัตโนมัติหลังหยุดพิมพ์ 650 ms และเมื่อออกจากหน้า
- ตัวหนา ตัวเอียง และเช็กลิสต์แบบแตะสลับ ☐ / ☑ ที่บรรทัดปัจจุบัน
- นำเข้าไฟล์ หรือแนบเอกสารที่เก็บไว้แล้วกับโน้ตโดยไม่คัดลอกซ้ำ
- PDF: ซูมด้วยสองนิ้ว ลากเลื่อน เปลี่ยนหน้า/เลือกเลขหน้า จำหน้าที่อ่าน บุ๊กมาร์ก และบันทึกประกอบแต่ละหน้า
- สำรองโน้ต ไฟล์แนบ บันทึก PDF และบุ๊กมาร์กเป็น ZIP เดียว กู้คืนแบบเพิ่มสำเนา ไม่ทับข้อมูลเดิม
- ส่งออกเอกสารต้นฉบับและแชร์ข้อความโน้ต

บันทึกประกอบ PDF เก็บแยกจากต้นฉบับ ยังไม่มีปากกา/ไฮไลต์หรือแก้ข้อความเดิมใน PDF
เช็กลิสต์ในตัวแก้ไขเป็นสัญลักษณ์ข้อความ ใช้ปุ่มรายการสลับสถานะที่บรรทัดปัจจุบัน
ไฟล์ชนิดอื่นเก็บและส่งออกได้ แต่ตัวอ่านภายในรองรับ PDF เท่านั้น
PDF ใส่รหัสผ่านยังไม่รองรับ การซูมจำกัด 1–5 เท่าและใช้ภาพเรนเดอร์ขนาดจำกัด

## ติดตั้งและอัปเดต

แพ็กเกจรุ่นใหม่: `com.notepocket.notes` / namespace: `com.notepocket.app`
รุ่นทดสอบสำหรับ CI: `com.notepocket.notes.debug` (ชื่อ NotePocket ทดลอง)
รุ่น 0.1 เดิม: `com.notepocket.app`

**อย่าลบแอป 0.1 หากยังมีข้อมูลที่ต้องการเก็บ** รุ่นนั้นลงนามด้วย debug key ที่เครื่อง CI สร้างชั่วคราว
ไม่ได้เก็บ private key ไว้ จึงไม่สามารถรับประกันการอัปเดตทับรุ่นนั้นได้
รุ่น 0.2 ใช้ package ใหม่เพื่อให้ติดตั้งอยู่ข้างรุ่นเดิมโดยไม่แตะข้อมูลเดิม
ข้อมูลในแอปเดิมจะไม่ถูกย้ายอัตโนมัติ: ส่งออกเอกสาร/แชร์ข้อความโน้ตเดิมแล้วนำเข้ารุ่นใหม่
หลังตั้งค่ากุญแจถาวร รุ่น release ต่อไปต้องใช้กุญแจเดียวกันและเพิ่ม `versionCode`

ไม่ควรแจก debug APK เป็นรุ่นใช้งานจริง ห้ามนำ debug APK ไปติดตั้งแทน release
หาก Android แจ้งว่าลายเซ็นไม่ตรง ให้หยุดและตรวจสอบ APK ไม่ควรถอนแอปเพื่อแก้ปัญหาโดยไม่สำรองข้อมูล

## กุญแจลงนามถาวร

ดู [docs/signing.md](docs/signing.md) ใช้ GitHub Actions secret เดียว: `ANDROID_SIGNING_BUNDLE`
ไม่มี private key หรือรหัสผ่านใน repository กุญแจต้องถูกเก็บสำรองโดยเจ้าของแอป
public certificate fingerprint อยู่ที่ `docs/release-certificate-sha256.txt`
workflow จะไม่สร้าง release APK ถ้ายังไม่ได้ตั้ง secret และไม่ใช้ debug key แทนโดยอัตโนมัติ

## สร้างและตรวจสอบ

เครื่องมือ: JDK 17, Gradle 8.9, Android SDK 35 / build tools 35.0.0

```sh
gradle assembleDebug assembleDebugAndroidTest lintDebug
```

ยังไม่มี Gradle wrapper ใน repository ใช้ Gradle ที่ติดตั้งแล้วหรือ GitHub Actions
workflow จะคอมไพล์ ตรวจ Lint ทดสอบ Android emulator API 35 ถ่ายภาพหน้าจอ
และติดตั้งทับด้วย `adb install -r` แล้วตรวจว่าโน้ต ไฟล์แนบ และบันทึกประกอบยังอยู่
ทดสอบการย้ายฐานข้อมูล 0.1 แบบ schema เดิม การกู้คืนที่ล้มเหลว และ ZIP path traversal ด้วย

เมื่อ secret พร้อมและการตรวจทั้งหมดผ่าน จะได้ artifact `NotePocket-0.2.0-install`
ซึ่งมี `app-release.apk` ลงนามด้วยกุญแจถาวร
ผลการตรวจและภาพหน้าจออยู่ใน artifact `NotePocket-QA-reports`
การทดสอบติดตั้งทับใน CI ใช้ debug package และ key เดียวกันใน job เดียว
ไม่ใช่หลักฐานว่าอัปเดตทับ APK รุ่น 0.1 ได้

## ข้อมูลและข้อจำกัด

ใช้ SQLite schema version 2 และ migration แบบเพิ่มคอลัมน์/ตารางโดยไม่ลบข้อมูล
ถังขยะใช้กับโน้ต การลบเอกสารจากคลังเป็นการลบถาวรและลบบันทึกประกอบของเอกสารนั้น
การเอาไฟล์แนบออกจากโน้ตจะเก็บไฟล์ไว้ในคลัง

แอปไม่สำรองขึ้นคลาวด์เองและปิด Android automatic backup
การถอนแอป/ล้างข้อมูลจะลบข้อมูลในพื้นที่แอป ควรใช้เมนูตั้งค่า → สำรองข้อมูล
ไฟล์สำรอง ZIP ไม่เข้ารหัส ให้เก็บในที่ปลอดภัย
นำเข้าเอกสารสูงสุด 512 MiB ต่อไฟล์ กู้คืน archive สูงสุด 1 GiB และ 10,000 entries
ข้อมูลจำนวนมาก/อุปกรณ์พื้นที่น้อยควรตรวจพื้นที่ว่างก่อน
ยังไม่ได้รับรองการใช้งานบนอุปกรณ์จริงทุกยี่ห้อ
