# NotePocket — แอปจดโน้ตและเก็บเอกสาร Android

สถานะ: รุ่นเริ่มต้น 0.1.0 มี GitHub Actions สำหรับคอมไพล์และตรวจ Android Lint
ตรวจผลและดาวน์โหลด APK ที่ผ่านการสร้างจากหน้า Actions ของโปรเจกต์
**ยังไม่ได้ทดสอบการใช้งานบนอุปกรณ์ Android จริง**

## ฟังก์ชันที่เขียนไว้

- สร้าง แก้ไข ลบ ค้นหาโน้ตภาษาไทย พร้อมบันทึกเมื่อออกจากหน้าจอ
- แชร์ข้อความโน้ตผ่านเมนูแชร์ของ Android
- นำเข้าไฟล์ด้วยตัวเลือกไฟล์ของ Android และคัดลอกไว้ในพื้นที่ส่วนตัวของแอป
- แนบ PDF หรือไฟล์กับโน้ตแต่ละรายการ และเปิดอ่าน PDF แล้วกลับมาแก้ไขโน้ตต่อ
- เอาไฟล์แนบออกจากโน้ตได้ โดยไฟล์ยังอยู่ในแท็บไฟล์
- ค้นหา ลบ และส่งออกไฟล์ผ่านตัวเลือกตำแหน่งบันทึกของ Android
- แสดง PDF ภายในแอป พร้อมปุ่มเปลี่ยนหน้า
- ทำงานออฟไลน์ ไม่ต้องมีบัญชี ไม่ขอสิทธิ์อินเทอร์เน็ตหรือสิทธิ์เข้าถึงไฟล์ทั้งหมด

การแก้ไขในรุ่นนี้หมายถึง **แก้ไขโน้ต** ยังไม่มีการแก้ข้อความเดิม ขีดไฮไลต์ เขียนทับ PDF ซูม PDF หรือสั่งพิมพ์ออกเครื่องพิมพ์
ไฟล์ประเภทอื่นเก็บและส่งออกได้ แต่ยังไม่มีตัวอ่านภายในแอป
PDF ที่ล็อกด้วยรหัสผ่านยังไม่รองรับ

## สร้าง APK ด้วย Android Studio

1. ติดตั้ง Android Studio รุ่นที่รองรับ Android Gradle Plugin 8.7.3
2. เปิดโฟลเดอร์ `NotePocket` และติดตั้ง Android SDK Platform 35 ตามคำแนะนำของ IDE
3. ใช้ JDK 17 ขึ้นไปและ Gradle 8.9 สำหรับโปรเจกต์นี้ (ยังไม่ได้ใส่ Gradle wrapper)
4. เลือก Build → Build App Bundle(s) / APK(s) → Build APK(s)
5. ไฟล์จะอยู่ที่ `app/build/outputs/apk/debug/app-debug.apk`

ถ้ามี Gradle 8.9 และ SDK ติดตั้งแล้ว ใช้ `gradle assembleDebug lintDebug`
ไฟล์ debug APK ใช้ติดตั้งเพื่อทดลองได้ การแจกจ่ายรุ่นจริงควรสร้าง signed release APK
และเก็บกุญแจลงนามไว้สำหรับอัปเดตแอปในอนาคต

## ทางเลือกผ่าน GitHub Actions

มี workflow `.github/workflows/android.yml` สำหรับติดตั้งเครื่องมือ สร้าง debug APK
และรัน Android Lint เมื่ออัปโหลดโปรเจกต์เข้าที่เก็บ GitHub ของคุณ
จากนั้นดาวน์โหลด artifact ชื่อ `NotePocket-debug-apk` ในหน้า Actions
โปรเจกต์อยู่ที่ https://github.com/pharmdever/NotePocket และ workflow จะเริ่มเมื่อ push โค้ด

## ก่อนใช้งานกับข้อมูลจริง

ควรตรวจบน Android 8 ขึ้นไป: สร้างและแก้โน้ต → ปิดแล้วเปิดแอป → ค้นหา → ลบ,
หมุนหน้าจอขณะแก้ไข, นำเข้าไฟล์แล้วลบต้นฉบับเพื่อยืนยันว่ามีสำเนาในแอป,
อ่าน PDF หลายหน้า, ไฟล์เสียหรือมีรหัสผ่าน, ส่งออกแล้วเปิดไฟล์ที่ส่งออก,
และยกเลิกตัวเลือกไฟล์โดยไม่มีข้อมูลหาย
ตรวจเพิ่ม: แนบ PDF สองไฟล์กับโน้ตหนึ่งรายการ → เปิดอ่านและกลับไปโน้ต →
เอาไฟล์แนบออกหนึ่งไฟล์ → ปิดแล้วเปิดแอป → ตรวจว่าอีกไฟล์ยังแนบอยู่
การลบโน้ตจะเอาความเชื่อมโยงไฟล์แนบออก แต่คงไฟล์ไว้ในแท็บไฟล์
การลบไฟล์ในแท็บไฟล์จะลบไฟล์และความเชื่อมโยงกับทุกโน้ตที่แนบไฟล์นั้น

ข้อมูลอยู่ในพื้นที่แอปและไม่ซิงก์หรือสำรองอัตโนมัติ การล้างข้อมูลหรือถอนการติดตั้ง
จะลบข้อมูลในแอป โปรดส่งออกไฟล์และแชร์ข้อความโน้ตที่ต้องการเก็บก่อน
